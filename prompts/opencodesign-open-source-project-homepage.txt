FRAMEWELL COLLECTION EXPANSION

Build this as a complete, copy-pasteable frontend artifact, not a tiny component. Use React + Vite or Next.js, TypeScript, Tailwind CSS, and shadcn/ui primitives only where they genuinely improve the result. If a chart, map, product screenshot, avatar, or image is needed, create it with CSS/SVG/inline mock data instead of hotlinking external assets.

Quality bar:
- Make the composition feel designed, not template-generated: strong hierarchy, specific product copy, real labels, believable metrics, and no lorem ipsum.
- Include responsive behavior for mobile, tablet, and desktop.
- Add polished interaction states: hover, focus, active, selected, empty/error/loading where the surface calls for it.
- Use accessible contrast, keyboard-visible controls, semantic landmarks, and reduced-motion fallbacks for any animation.
- Keep visual style cohesive: pick one strong aesthetic direction and carry it through typography, spacing, color, borders, and motion.
- Return all code needed for the page/screen and avoid TODO placeholders.
