Quality bar:

- Include responsive behavior for mobile, tablet, and desktop.
- Add polished interaction states: hover, focus, active, selected, empty/error/loading where the surface calls for it.
- Use accessible contrast, keyboard-visible controls, semantic landmarks, and reduced-motion fallbacks for any animation.
- Keep visual style cohesive: pick one strong aesthetic direction and carry it through typography, spacing, color, borders, and motion.
- Return all code needed for the page/screen and avoid TODO placeholders.
